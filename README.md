GlamHub Ecommerce Sales Dashboard

Overview:

The GlamHub Ecommerce Sales Dashboard is an interactive Power BI visualization that provides key insights into sales performance, revenue trends, and customer purchasing behavior. It helps businesses analyze their sales data efficiently and make data-driven decisions.

Features:

Key Performance Indicators (KPIs): Displays total revenue, profit, sales quantity, and average order value (AOV).

Sales Breakdown by State: Identifies top-performing regions.

Category & Subcategory Insights: Analyzes sales performance across different product categories and subcategories.

Customer & Payment Mode Analytics: Tracks purchases based on customer names and preferred payment methods.

Profit Trends by Month: Visualizes monthly profit trends for the year.

Quarterly Filters: Enables users to filter data based on quarters for better trend analysis.
